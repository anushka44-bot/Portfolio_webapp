# 🧠 Personal Portfolio Website

This is my personal portfolio website showcasing my skills, projects, experience, and contact information.

## ✨ Features

* 🧑‍💻 **Responsive Portfolio**
  A modern, responsive UI with sections like:

  * Home
  * About Me
  * Skills
  * Projects
  * Contact

* 🛠️ **Skills Section**
  Highlights my technical skills and technologies, including:

  * HTML
  * CSS
  * JavaScript
  * React.js
  * Node.js
  * Express.js
  * MongoDB
  * SQL
  * Git & GitHub

* 📂 **Projects**
  Showcases my web development projects, including:

  * **LuxeCart** – A full-stack e-commerce website
  * **Aurevia** – An online doctor appointment booking website

* 📩 **Contact**
  Allows visitors to get in touch with me through the contact form.

## 🚀 Tech Stack

* **Frontend:** HTML, CSS, JavaScript, React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, SQL
* **Tools:** Git, GitHub, VS Code
* **Responsive Design:** Mobile-first UI

## 🛠️ Setup Instructions

1. Clone the repository:

```bash
git clone https://github.com/anushka44-bot/AI_Portfolio.git
```

2. Navigate to the project folder:

```bash
cd AI_Portfolio
```

3. Open the project in your preferred code editor.

4. Run the website using a local development server or open the HTML file in your browser.
